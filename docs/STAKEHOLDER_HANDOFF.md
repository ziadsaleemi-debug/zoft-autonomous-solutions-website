# Stakeholder Handoff — Company Website v0.1

## Initiative
Create the first public website for the autonomous software development and IT solutions company.

## Passed Instructions
- Build a company website.
- Ensure the right stakeholders are involved.
- Track the work.
- Document the work.
- Push code to GitHub.
- Include an agent that collects sales/client-start information.

## Acceptance Criteria

- Website has clear hero, services, operating model, and CTA.
- Website includes a Sales Concierge Agent intake flow.
- Intake flow collects company/name, need, timeline, budget, and details.
- Intake flow generates a recommended internal routing brief.
- No secrets are included in frontend code.
- Build passes locally.
- Delivery is documented.
- Code is pushed to GitHub.
