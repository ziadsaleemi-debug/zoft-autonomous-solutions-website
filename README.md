# Zoft Autonomous Solutions Website

Company website for an autonomous software development and IT solutions company.

## Purpose

- Explain company services.
- Show the stakeholder/role-agent delivery model.
- Provide a front-end Sales Concierge Agent that collects client intake details and creates a getting-started brief.

## Stack

- React
- Vite
- CSS

## Run

```bash
npm install
npm run build
npm run start
```

## Governance

This first delivery run involved the required company stakeholders through documented role packets in `docs/STAKEHOLDER_HANDOFF.md` and delivery evidence in `docs/DELIVERY_RECORD.md`.

High-risk actions still require human approval: production deployment, paid services, credential changes, external client communications, and destructive operations.
